# Fitrack

Application mobile de suivi d'entraînement, pensée pour les sportifs qui veulent progresser sans prise de tête.

## C'est quoi ?

Fitrack, c'est ton carnet d'entraînement de poche. Tu logges tes séances, tu suis ta progression, tu défis tes potes — le tout dans une interface clean et rapide.

## Fonctionnalités

### Tracker tes séances

- Musculation, crossfit, running, vélo
- Exercices avec séries, reps et charges
- Objectifs endurance (distance, vitesse, dénivelé)
- Export et import de séances (partage facile)

### Progresser

- Records personnels automatiques
- Historique complet de tes séances
- Graphiques de progression
- Suivi du poids de corps

### Rester motivé

- 19 badges à débloquer (4 raretés)
- Système de niveaux et d'XP
- Streak quotidien avec flamme animée
- 23 défis quotidiens avec explications détaillées

### S'entraîner entre amis

- Ajoute tes amis par QR code, code ami ou email
- Classement mensuel
- Demandes d'amitié
- Chaque utilisateur a son code ami unique

### Personnaliser

- Mode clair et sombre
- Couleur d'accent personnalisable
- Photo de profil
- Interface cohérente et sans fioritures

## Télécharger

Bientôt disponible sur l'App Store et Google Play.
